# ZIMRA Fiscalization Overview

**HavanoZimra Cloud** is an enterprise-grade cloud API bridge designed to integrate ERP platforms, accounting systems, Point of Sale (POS) terminals, and custom billing software with the **Zimbabwe Revenue Authority (ZIMRA)** Fiscal Data Management System (FDMS).

Under Zimbabwean fiscal legislation (including Statutory Instrument 153 of 2024 and SI 65A of 2020), all registered operators must connect their billing systems to ZIMRA fiscal devices or approved virtual fiscal systems to generate cryptographically verified fiscal tax invoices in real time.

```
+--------------------------+         +-------------------------------+         +---------------------+
|                          |  HTTPS  |                               |  HTTPS  |                     |
|  Your ERP / POS System   | ------->|   HavanoZimra Cloud Gateway   | ------->|   ZIMRA FDMS Host   |
|  (SAP, Odoo, custom app) | <-------|   (Token, Validation, Sign)   | <-------|   (Gov Server)      |
|                          |         |                               |         |                     |
+--------------------------+         +-------------------------------+         +---------------------+
```

---

## Why Use HavanoZimra Cloud?

Integrating directly with ZIMRA hardware devices or raw fiscal interfaces presents numerous challenges:
- **Complex Cryptography**: Direct fiscalization requires strict device-level signing, public-key verification, and proprietary hardware protocols.
- **Maintenance & Uptime**: Handling connection loss to government servers, retry queues, and device failovers requires significant custom development.
- **Simplified REST API**: HavanoZimra Cloud replaces intricate low-level communications with clean, standardized REST endpoints accepting standard form data and JSON.
- **Built-in Offline Support**: Seamless fallback to offline invoice buffering when ZIMRA servers experience downtime or latency spikes.

## Key Terminology

Before starting integration, familiarize yourself with these key terms used across the API:

| Term | Definition |
| :--- | :--- |
| **Device SN** (`device_sn`) | The unique Fiscal Device Serial Number assigned to your registered fiscal device or virtual fiscalizer by ZIMRA. |
| **BP Number / TIN** | Business Partner Number and Taxpayer Identification Number issued to your entity by ZIMRA. |
| **VAT Number** | The Value Added Tax registration number for VAT-registered businesses in Zimbabwe. |
| **Global Invoice No** (`global_invoice_no`) | The official sequential fiscal receipt number assigned by ZIMRA upon successful fiscalization of an invoice. Required for credit notes. |
| **Invoice Flag** (`invoice_flag`) | Distinguishes transaction type: `0` for Standard Sales Invoice, `1` for Credit Note. |
| **Items XML** (`items_xml`) | Structured XML payload detailing item codes, descriptions, quantities, unit prices, line totals, and VAT tax category codes. |
