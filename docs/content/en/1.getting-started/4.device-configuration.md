# Device Configuration & Management

Every fiscal transaction routed through HavanoZimra Cloud requires an authorized **Fiscal Device Serial Number** (`device_sn`). This serial number binds the transaction to your company's registered taxpayer profile with ZIMRA.

---

## Device Registration Workflow

```
+--------------------------+       +-----------------------------+       +-------------------------+
|                          |       |                             |       |                         |
|  1. Purchase / Allocate  | ----> | 2. Map Device SN in Cloud   | ----> | 3. Ping & Verify Status |
|     Fiscal Device SN     |       |    Link to User Profile     |       |    Ready for Invoicing  |
|                          |       |                             |       |                         |
+--------------------------+       +-----------------------------+       +-------------------------+
```

1. **ZIMRA Allocation**: ZIMRA or an approved fiscalization provider registers the physical device or virtual fiscalizer and issues an official device serial number (e.g. `1234567890`).
2. **HavanoZimra Cloud Mapping**: The device serial number is linked to your user account and tax profile inside HavanoZimra Cloud.
3. **Connectivity Verification**: Use the `pingzimra` endpoint to ensure the device is active and communicating with ZIMRA's server.

---

## Device Status Verification

Before processing invoices in a production environment, test device health using the `pingzimra` endpoint:

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.pingzimra \
  -H "Authorization: token YOUR_KEY:YOUR_SECRET" \
  -H "X-Frappe-CSRF-Token: YOUR_CSRF_TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890"
```

### Response Scenarios

| Scenario | Response Code | Message / Error | Action Required |
| :--- | :--- | :--- | :--- |
| **Active & Connected** | `0` | `"Ping successful"` | Ready to fiscalize transactions. |
| **Unmapped Device** | Error | `"Zimra User Account not found for Device SN: 1234567890 or Account disabled"` | Contact Havano administrator to register or enable the device SN under your account. |
| **Missing Parameter** | Error | `"Missing required parameters: 'Device serial number'"` | Ensure `device_sn` parameter is included in the form body. |
| **ZIMRA Server Down** | Error | `"Connection timeout"` or `"Host unreachable"` | Switch temporarily to [Offline Invoicing](/en/api-reference/offline-invoicing). |

## Multi-Device / Multi-Till Setup

In retail and enterprise ERP environments with multiple points of sale (POS) or multiple branches:
- Each physical till, terminal, or warehouse station can have its own dedicated `device_sn`.
- Your ERP should store the assigned `device_sn` per register or POS terminal.
- Submissions from different tills run concurrently through the cloud gateway without interfering with each other's sequential receipt numbering.
