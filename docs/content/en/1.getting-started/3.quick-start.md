# Quick Start Guide

This guide walks you through the complete lifecycle of submitting your first fiscal invoice to ZIMRA via HavanoZimra Cloud.

---

## Step 1: Collect Your Prerequisites

Before executing requests, ensure you have:
1. **Cloud Base URL**: `https://your-site-name` (provided by Havano Systems).
2. **API Key & API Secret**: Generated from your Havano user profile or Frappe administrator.
3. **Registered Device Serial Number (`device_sn`)**: The serial number assigned to your fiscal device or virtual fiscalizer by ZIMRA.

---

## Step 2: Retrieve a CSRF Token

First, call the token endpoint to initialize the session:

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.token
```

**Response:**
```json
{
  "token": "a9f8e7c2f23d46a89c0b1e4f5a6b7c8d9e0f"
}
```

Store this token value in a variable, e.g. `CSRF_TOKEN`.

---

## Step 3: Ping ZIMRA to Verify Connectivity

Before sending invoices, verify that your device is recognized and the ZIMRA FDMS server is reachable:

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.pingzimra \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: a9f8e7c2f23d46a89c0b1e4f5a6b7c8d9e0f" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890"
```

**Expected Success Response:**
```json
{
  "ResponseCode": "0",
  "ResponseMessage": "Ping successful",
  "DeviceSN": "1234567890"
}
```

> [!TIP]
> A `ResponseCode` of `"0"` indicates complete end-to-end communication from HavanoZimra Cloud to ZIMRA servers.

---

## Step 4: Submit a Test Fiscal Invoice

Now send a test sales invoice with item details encoded in XML:

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.sendinvoice \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: a9f8e7c2f23d46a89c0b1e4f5a6b7c8d9e0f" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890" \
  -d "add_customer=0" \
  -d "invoice_flag=0" \
  -d "currency=USD" \
  -d "invoice_number=INV-2026-0001" \
  -d "customer_name=John Doe" \
  -d "trade_name=JD Traders" \
  -d "customer_vat_number=12345678" \
  -d "customer_address=123 Samora Machel Ave" \
  -d "customer_telephone_number=+263771234567" \
  -d "customer_tin=87654321" \
  -d "customer_province=Harare" \
  -d "customer_street=Samora Machel" \
  -d "customer_houseNo=123" \
  -d "customer_city=Harare" \
  -d "customer_email=john@example.com" \
  -d "invoice_comment=Test sales invoice" \
  -d "original_invoice_no=" \
  -d "global_invoice_no=" \
  --data-urlencode "items_xml=<ITEMS><ITEM><HH>1</HH><ITEMCODE>ITEM001</ITEMCODE><ITEMNAME>Mineral Water 500ml</ITEMNAME><ITEMNAME2>Mineral Water 500ml</ITEMNAME2><QTY>2</QTY><PRICE>1.00</PRICE><TOTAL>2.00</TOTAL><VAT>0.26</VAT><VATR>0.15</VATR><VNAME>VAT</VNAME></ITEM></ITEMS>"
```

**Expected JSON Response:**
```json
{
  "ResponseCode": "0",
  "ResponseMessage": "Invoice successfully processed",
  "DeviceSN": "1234567890",
  "InvoiceNumber": "INV-2026-0001",
  "GlobalInvoiceNo": "100452",
  "FiscalDay": "24",
  "VerificationURL": "https://efms.zimra.co.zw/verify/..."
}
```

---

## Step 5: Handle the Output in Your ERP / POS

When `ResponseCode` is `"0"`:
1. Save `GlobalInvoiceNo` against the invoice record in your ERP database.
2. Store the verification URL or fiscal QR signature returned by the gateway.
3. Print the fiscal receipt or PDF tax invoice with the official ZIMRA fiscal signature.
