# cURL & REST Reference

Use these cURL commands for quick terminal testing, CI/CD health checks, or setting up your Postman/Insomnia environment.

---

## 1. Get CSRF Token

```bash
curl -i -X POST "https://your-site-name/api/method/havanozimracloud.api.token"
```

**Save token to variable:**

```bash
TOKEN=$(curl -s -X POST "https://your-site-name/api/method/havanozimracloud.api.token" | jq -r '.token // .message')
echo "Token: $TOKEN"
```

---

## 2. Ping ZIMRA Server

```bash
curl -i -X POST "https://your-site-name/api/method/havanozimracloud.api.pingzimra" \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: $TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890"
```

---

## 3. Send Fiscal Sales Invoice

```bash
curl -i -X POST "https://your-site-name/api/method/havanozimracloud.api.sendinvoice" \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: $TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890" \
  -d "add_customer=0" \
  -d "invoice_flag=0" \
  -d "currency=USD" \
  -d "invoice_number=INV-CURL-001" \
  -d "customer_name=John Doe" \
  -d "trade_name=JD Traders" \
  -d "customer_vat_number=12345678" \
  -d "customer_address=123 Market Street" \
  -d "customer_telephone_number=+263771234567" \
  -d "customer_tin=87654321" \
  -d "customer_province=Harare" \
  -d "customer_street=Market Street" \
  -d "customer_houseNo=12" \
  -d "customer_city=Harare" \
  -d "customer_email=john@example.com" \
  -d "invoice_comment=Over-the-counter sale" \
  -d "original_invoice_no=" \
  -d "global_invoice_no=" \
  --data-urlencode 'items_xml=<ITEMS><ITEM><HH>1</HH><ITEMCODE>99001868</ITEMCODE><ITEMNAME>Milo 500g</ITEMNAME><ITEMNAME2>Milo</ITEMNAME2><QTY>1</QTY><PRICE>6.10</PRICE><TOTAL>6.10</TOTAL><VAT>0.80</VAT><VATR>0.15</VATR><VNAME>VAT</VNAME></ITEM></ITEMS>'
```
