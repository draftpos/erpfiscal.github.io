## 1. Environment Setup

Create a new Postman Environment containing the following variables:

| Variable | Initial Value | Description |
| :--- | :--- | :--- |
| `baseUrl` | `https://your-site-name` | Your HavanoZimra Cloud base URL (without trailing slash). |
| `apiKey` | `YOUR_API_KEY` | Frappe API key generated from user settings. |
| `apiSecret` | `YOUR_API_SECRET` | Frappe API secret key. |
| `deviceSn` | `1234567890` | Your registered ZIMRA fiscal device serial number. |
| `csrfToken` | *(leave empty)* | Automatically populated by the Token request script. |

---

## 2. Automated CSRF Token Extraction

In Postman, under the **Tests** tab of the `1. Get CSRF Token` request, paste this script:

```javascript
// Automatically extract and set csrfToken in the active environment
const jsonData = pm.response.json();
const token = jsonData.token || jsonData.message;

if (token) {
    pm.environment.set("csrfToken", token);
    console.log("CSRF Token successfully stored:", token);
} else {
    console.error("Token key not found in response:", jsonData);
}
```

Now, every subsequent request in the collection can use:
- **Header**: `X-Frappe-CSRF-Token: {{csrfToken}}`
- **Header**: `Authorization: token {{apiKey}}:{{apiSecret}}`
