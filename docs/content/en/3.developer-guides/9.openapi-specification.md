# OpenAPI 3.0 Specification

HavanoZimra Cloud provides an OpenAPI 3.0 (formerly Swagger) definition file. You can import this specification directly into API gateways, Postman, Swagger UI, or code generation tools such as `openapi-generator-cli`.

## Generating Client SDKs

Using the open-source [OpenAPI Generator](https://openapi-generator.tech/), you can generate native client libraries:

### Generate C# Client

```bash
npx @openapitools/openapi-generator-cli generate \
  -i https://your-site-name/openapi.yaml \
  -g csharp \
  -o ./clients/csharp
```

### Generate Python Client

```bash
npx @openapitools/openapi-generator-cli generate \
  -i https://your-site-name/openapi.yaml \
  -g python \
  -o ./clients/python
```

### Generate Go Client

```bash
npx @openapitools/openapi-generator-cli generate \
  -i https://your-site-name/openapi.yaml \
  -g go \
  -o ./clients/go
```

### Generate Java / Kotlin Client

```bash
npx @openapitools/openapi-generator-cli generate \
  -i https://your-site-name/openapi.yaml \
  -g java \
  -o ./clients/java
```

## Interactive Swagger UI

If you host Swagger UI or use online viewers (such as [Editor.Swagger.io](https://editor.swagger.io/)), upload `openapi.yaml` to view an interactive dashboard of all HavanoZimra Cloud parameters, validation models, and schemas.
