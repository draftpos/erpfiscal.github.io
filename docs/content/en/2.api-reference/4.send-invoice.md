# Send Invoice to ZIMRA

Submits a fiscal sales invoice or credit note to the ZIMRA Fiscal Data Management System (FDMS) via your registered device.

---

## Endpoint Details

- **Method**: `POST`
- **Path**: `/api/method/havanozimracloud.api.sendinvoice`
- **Authentication**: Required (`Authorization` + `X-Frappe-CSRF-Token`)
- **Content-Type**: `application/x-www-form-urlencoded`

---

## Request Parameters

All parameters should be transmitted in the URL-encoded POST body.

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `device_sn` | `string` | **Yes** | Device Serial Number assigned by ZIMRA. |
| `add_customer` | `int` | **Yes** | Flag to save/update customer in cloud (`1` = Yes, `0` = No). |
| `invoice_flag` | `int` | **Yes** | Transaction type: `0` = Sales Invoice, `1` = Credit Note. |
| `currency` | `string` | **Yes** | Three-letter currency code (e.g., `USD`, `ZIG`). |
| `invoice_number` | `string` | **Yes** | Unique internal invoice number from your ERP/POS (e.g., `INV00123`). |
| `customer_name` | `string` | **Yes** | Customer full legal name or individual name. |
| `trade_name` | `string` | **Yes** | Trading name of the customer company (or customer name if none). |
| `customer_vat_number` | `string` | **Yes** | Customer's ZIMRA VAT registration number (or empty string/N/A if non-VAT). |
| `customer_address` | `string` | **Yes** | Full physical address. |
| `customer_telephone_number` | `string` | **Yes** | Customer contact phone number (e.g. `+263771234567`). |
| `customer_tin` | `string` | **Yes** | Taxpayer Identification Number (TIN / BP number). |
| `customer_province` | `string` | **Yes** | Province / Region (e.g., `Harare`, `Bulawayo`, `Manicaland`). |
| `customer_street` | `string` | **Yes** | Street name. |
| `customer_houseNo` | `string` | **Yes** | House / Building / Suite number (also accepted as `customer_house_no`). |
| `customer_city` | `string` | **Yes** | City or town. |
| `customer_email` | `string` | **Yes** | Customer email address for fiscal invoice delivery. |
| `invoice_comment` | `string` | Conditional | Comment or note. **Mandatory** when `invoice_flag = 1` (Credit Note). |
| `original_invoice_no` | `string` | Conditional | Original invoice number. **Mandatory** when `invoice_flag = 1` (Credit Note). |
| `global_invoice_no` | `int` / `string` | Conditional | ZIMRA fiscal receipt number of original invoice. **Mandatory** when `invoice_flag = 1`. |
| `items_xml` | `string` | **Yes** | XML formatted string containing the itemized lines with quantities, amounts, and tax codes. |

---

## Example Request

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.sendinvoice \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: YOUR_CSRF_TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890" \
  -d "add_customer=0" \
  -d "invoice_flag=0" \
  -d "currency=USD" \
  -d "invoice_number=INV00123" \
  -d "customer_name=John Doe" \
  -d "trade_name=JD Traders" \
  -d "customer_vat_number=12345678" \
  -d "customer_address=123 Market Street" \
  -d "customer_telephone_number=+263771234567" \
  -d "customer_tin=87654321" \
  -d "customer_province=Harare" \
  -d "customer_street=Market Street" \
  -d "customer_houseNo=12" \
  -d "customer_city=Harare" \
  -d "customer_email=john@example.com" \
  -d "invoice_comment=Sales transaction" \
  -d "original_invoice_no=" \
  -d "global_invoice_no=" \
  --data-urlencode 'items_xml=<ITEMS><ITEM><HH>1</HH><ITEMCODE>99001868</ITEMCODE><ITEMNAME>Milo 500g</ITEMNAME><ITEMNAME2>Milo 500g</ITEMNAME2><QTY>1</QTY><PRICE>6.10</PRICE><TOTAL>6.10</TOTAL><VAT>0.80</VAT><VATR>0.15</VATR><VNAME>VAT</VNAME></ITEM></ITEMS>'
```

  "InvoiceNumber": "INV00123",

---

## Possible Errors

### Duplicate Invoice Number
Each invoice number submitted for a given user and device must be globally unique:

```json
{
  "ResponseCode": "1",
  "ResponseMessage": "Invoice Number Already exist for this User, Please change invoice number format: INV00123 cannot be used"
}
```

*Solution*: Ensure your ERP generates a unique invoice reference for each transaction.

### Missing or Disabled ZIMRA Account

```json
{
  "ResponseCode": "1",
  "ResponseMessage": "Zimra User Account not found for Device SN: 1234567890 or Account disabled"
}
```

*Solution*: Check that `device_sn` matches your assigned device and that your account status is enabled in HavanoZimra Cloud.

### Missing Required Fields

```json
{
  "success": false,
  "message": "Missing required parameters: 'Device serial number'"
}
```
