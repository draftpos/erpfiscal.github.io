# Get CSRF Token

Generates (if not already generated) and returns a session CSRF token. The token returned by this endpoint is required in the `X-Frappe-CSRF-Token` header for all subsequent API calls.

---

## Endpoint Details

- **Method**: `POST` *(or `GET`)*
- **Path**: `/api/method/havanozimracloud.api.token`
- **Authentication**: None required (public entrypoint for session initialization)
- **Request Body**: None

---

## Request Example

### cURL

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.token
```

### HTTP Request

```http
POST /api/method/havanozimracloud.api.token HTTP/1.1
Host: your-site-name
Content-Length: 0
```

---

## Response

### Status Code: `200 OK`

```json
{
  "token": "a9f8e7c2f23d46a89c0b1e4f5a6b7c8d9e0f"
}
```

> [!NOTE]
> Depending on your Frappe server version, the JSON response may return the token mapped to either `"token"` or `"message"`. Example:
> ```json
> {
>   "message": "a9f8e7c2f23d46a89c0b1e4f5a6b7c8d9e0f"
> }
> ```
> To ensure compatibility across setups, check for `data.ContainsKey("token")` first, and fallback to `data("message")`.

---

## Client Integration Note

When requesting a token in .NET or other client runtimes, passing default session cookies (such as `full_name=Guest`, `sid=Guest`, `system_user=no`, `user_id=Guest`) via a `CookieContainer` ensures consistent session state persistence across your request pipeline.
