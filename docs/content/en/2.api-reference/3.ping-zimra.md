# Ping ZIMRA Server

Pings the ZIMRA FDMS server to verify connectivity and validate that the specified device serial number is registered and active in the system.

---

## Endpoint Details

- **Method**: `POST`
- **Path**: `/api/method/havanozimracloud.api.pingzimra`
- **Authentication**: Required (`Authorization` + `X-Frappe-CSRF-Token`)
- **Content-Type**: `application/x-www-form-urlencoded`

---

## Request Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `device_sn` | `string` | **Yes** | The fiscal device serial number assigned by ZIMRA to ping and verify. |

---

## Example Request

### cURL

```bash
curl -X POST https://your-site-name/api/method/havanozimracloud.api.pingzimra \
  -H "Authorization: token YOUR_API_KEY:YOUR_API_SECRET" \
  -H "X-Frappe-CSRF-Token: YOUR_CSRF_TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "device_sn=1234567890"
```

---

## Success Response

### JSON

```json
{
  "ResponseCode": "0",
  "ResponseMessage": "Ping successful",
  "DeviceSN": "1234567890"
}
```

---

## Possible Errors

### Missing Device Serial Number

Returned if `device_sn` is omitted from the request body:

```json
{
  "success": false,
  "message": "Missing required parameters: 'Device serial number'"
}
```

### Unregistered or Disabled Account

Returned if the specified `device_sn` is not associated with an active ZIMRA user account in HavanoZimra Cloud:

```json
{
  "ResponseCode": "1",
  "ResponseMessage": "Zimra User Account not found for Device SN: 1234567890 or Account disabled"
}
```

---

## Best Practice

Call this endpoint during application startup, at the beginning of each billing shift, or before batch invoice synchronization to verify the fiscal device status and live communication with ZIMRA servers.
