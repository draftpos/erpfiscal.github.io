# API Reference Overview

The HavanoZimra Cloud API uses standard REST architecture over HTTPS. All requests accept standard form URL-encoded bodies or query parameters and return standard JSON responses.

---

## Base URL

Configure your client application with your assigned cloud instance URL:

```http
https://your-site-name/api/method/
```

> [!IMPORTANT]
> Replace `your-site-name` with the actual domain or IP address of your HavanoZimra Cloud deployment (e.g. `https://fiscal.havano.co.zw` or `https://cloud.erpfiscal.co.zw`).

---

## Endpoints Summary

| Endpoint | HTTP Method | Auth Required | Description |
| :--- | :--- | :--- | :--- |
| [`havanozimracloud.api.token`](/en/api-reference/token) | POST / GET | No | Generates and returns a session CSRF token. |
| [`havanozimracloud.api.pingzimra`](/en/api-reference/ping-zimra) | POST | Yes | Tests end-to-end connectivity between device and ZIMRA FDMS. |
| [`havanozimracloud.api.sendinvoice`](/en/api-reference/send-invoice) | POST | Yes | Sends a sales invoice (`invoice_flag=0`) or credit note (`invoice_flag=1`). |
| [`havanozimracloud.api.sendinvoice` (Offline)](/en/api-reference/offline-invoicing) | POST | Yes | Submits queued offline invoices once ZIMRA connectivity is restored. |

---

## Standard Request Headers

Except for the token endpoint, all requests must provide:

```http
Authorization: token <API_KEY>:<API_SECRET>
X-Frappe-CSRF-Token: <CSRF_TOKEN>
Content-Type: application/x-www-form-urlencoded
```

---

## Response Structure

Responses are returned in JSON format. Successful calls return a `ResponseCode` of `"0"`.

### Success Response Example

```json
{
  "ResponseCode": "0",
  "ResponseMessage": "Invoice successfully processed",
  "DeviceSN": "1234567890",
  "InvoiceNumber": "INV00123",
  "GlobalInvoiceNo": "100452"
}
```

### Error Response Example

In case of validation, fiscal, or connection errors, the response will contain error details:

```json
{
  "success": false,
  "message": "Missing required parameters: 'Device serial number'"
}
```

or:

```json
{
  "ResponseCode": "1",
  "ResponseMessage": "Invoice Number Already exist for this User, Please change invoice number format: INV00123 cannot be used"
}
```
