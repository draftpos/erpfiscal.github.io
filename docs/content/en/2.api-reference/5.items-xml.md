# Items XML Specification

The `items_xml` parameter encapsulates the line-item details of the fiscal invoice. It is transmitted as a string-encoded XML document containing one or more `<ITEM>` blocks inside a parent `<ITEMS>` tag.

> [!IMPORTANT]
> All XML fields within each `<ITEM>` block are **strictly required**. Your application must supply every element for ZIMRA compliance.

---

## XML Schema & Tag Reference

```xml
<ITEMS>
  <ITEM>
    <HH>1</HH>
    <ITEMCODE>99001868</ITEMCODE>
    <ITEMNAME>Milo 500g</ITEMNAME>
    <ITEMNAME2>Milo 500g</ITEMNAME2>
    <QTY>1</QTY>
    <PRICE>6.10</PRICE>
    <TOTAL>6.10</TOTAL>
    <VAT>0.80</VAT>
    <VATR>0.15</VATR>
    <VNAME>VAT</VNAME>
  </ITEM>
</ITEMS>
```

### Element Descriptions

| Tag | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `<HH>` | Integer | **Yes** | Line item sequential index (1, 2, 3...). | `1` |
| `<ITEMCODE>` | String | **Yes** | Product code, barcode, or internal SKU. | `99001868` |
| `<ITEMNAME>` | String | **Yes** | Primary item description (printed on fiscal receipt). | `Milo Refill 500g` |
| `<ITEMNAME2>` | String | **Yes** | Secondary description, translated text, or classification. | `Milo Refill 500g` |
| `<QTY>` | Decimal | **Yes** | Quantity sold (up to 4 decimal places). | `1` or `2.5` |
| `<PRICE>` | Decimal | **Yes** | Unit price of the item. | `6.10` |
| `<TOTAL>` | Decimal | **Yes** | Total line amount (`QTY * PRICE`). | `6.10` |
| `<VAT>` | Decimal | **Yes** | Total VAT amount for this line item. | `0.80` |
| `<VATR>` | Decimal | **Yes** | VAT rate represented as a decimal fraction (`0.15` for 15%, `0.00` for 0%). | `0.15` |
| `<VNAME>` | String | **Yes** | ZIMRA Tax category name (`VAT`, `ZERO RATED`, `EXEMPT`). | `VAT` |

---

## ZIMRA Tax Classifications

ZIMRA recognizes three primary Value Added Tax classifications in the XML payload:

| Classification | `<VATR>` | `<VNAME>` | Description & Common Usage |
| :--- | :--- | :--- | :--- |
| **Standard Rate** | `0.15` | `VAT` | Standard goods and services subject to 15% VAT. |
| **Zero-Rated** | `0.00` | `ZERO RATED` | Basic foodstuffs (e.g. maize meal, milk, bread), export goods. |
| **Exempt** | `0.00` | `EXEMPT` | Financial services, educational fees, residential rentals. |

## Calculation Rules & Escaping

1. **VAT Rounding**: Calculate VAT to 2 decimal places per line item using standard banking rounding (round half up).
2. **Line Total Verification**: The line total must satisfy $\text{TOTAL} = \text{QTY} \times \text{PRICE}$.
3. **XML Character Escaping**: If your item descriptions contain special characters (`&`, `<`, `>`, `"`, `'`), ensure they are properly XML-escaped:
   - `&` $\rightarrow$ `&amp;`
   - `<` $\rightarrow$ `&lt;`
   - `>` $\rightarrow$ `&gt;`
   - `"` $\rightarrow$ `&quot;`
   - `'` $\rightarrow$ `&apos;`
4. **URL Encoding**: When sending the payload in `application/x-www-form-urlencoded` format, encode the entire XML string (e.g. `%3CITEMS%3E...`).
